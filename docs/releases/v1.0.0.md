# RepoPulse v1.0.0：首个正式版本

RepoPulse 按每日快照追踪候选 GitHub 仓库的 Star 净增长，通过多周期榜单、筛选、趋势图和 AI 中文解读，帮助你发现值得关注的开源项目。

这是首个正式版本，提供源码与 Docker Compose 自建方式。`main` 分支可能包含后续开发中的变更；安装此版本请使用 `v1.0.0` Tag。在线网站：<https://repopulse.slak7.cn>，网站运行版本与发布 Tag 独立维护。

## 1.0 包含什么

- 对比最近 1 / 7 / 14 / 30 天的 Star 净增长与增长率。
- 按语言、主题、Star 数筛选，搜索项目名称或简介。
- 查看仓库详情、历史趋势和 README。
- 自带 AI API Key，生成 README「总结翻译」或全文「中文译文」。
- 用静态演示数据快速体验，或配置 GitHub Token 采集真实数据。
- 提供中英文 README、贡献与安全指南、备份恢复及部署运维工具，采用 MIT 许可证。

## 从零体验

需要 Git、已启动的 Docker 引擎与 Compose v2。本地演示不需要 GitHub Token 或 AI API Key，只启动数据库、缓存、API 与前端；浏览榜单使用自带的演示数据。

**Bash**

```bash
git clone --branch v1.0.0 --depth 1 https://github.com/SSlaks/RepoPulse.git
cd RepoPulse
[ -f .env ] || cp .env.example .env
docker compose up -d --build --wait --wait-timeout 180 postgres redis api frontend
```

**PowerShell**

```powershell
git clone --branch v1.0.0 --depth 1 https://github.com/SSlaks/RepoPulse.git
cd RepoPulse
if (-not (Test-Path -LiteralPath .env)) { Copy-Item -LiteralPath .env.example -Destination .env }
docker compose up -d --build --wait --wait-timeout 180 postgres redis api frontend
```

已有克隆请跳过前两行，在仓库根目录执行剩余命令。打开 <http://localhost:3000>，API 文档位于 <http://localhost:8000/docs>；<http://localhost:8000/api/v1/ready> 应返回 HTTP `200` 和 `status: ok`。启动失败时运行 `docker compose logs --tail 100 api frontend migrate` 查看日志。

仅提供源码，不提供安装包或预构建镜像；GitHub Release 附带源码压缩包。生产自建使用独立的 `.env.production`，按 [v1.0.0 快速上手](https://github.com/SSlaks/RepoPulse/blob/v1.0.0/docs/getting-started.md) 与 [运维手册](https://github.com/SSlaks/RepoPulse/blob/v1.0.0/docs/operations.md) 准备镜像、迁移、域名和代理配置。

## 数据口径与限制

- 只覆盖 RepoPulse 当前跟踪的候选仓库，不代表全 GitHub 排名，也不复刻 GitHub Trending 算法。
- 每日采集快照，榜单不是实时 Star 变化。目标与基线按 UTC 日历日计算，基线必须精确命中 `as_of - period`；`net_delta = end_stars - start_stars`，`growth_rate = net_delta / start_stars`。
- 刚自建时不做历史回溯。缺少严格基线的条目显示“历史数据不足”；1 天周期的有效净增长需等次日快照，7 / 14 / 30 天周期需积累对应天数的快照。
- 已发布的历史榜单不回溯重算，后续数据更新不会改写既有排名。
- 真实采集需要 `GITHUB_TOKEN` 且额度充足，再启动 `worker` 与 `beat`；多个 Token 不构成独立额度。
- AI 功能依赖第三方服务和用户自己的 Key，费用与可用性由所选提供方决定。本次发布未对所有支持的提供方执行真实付费调用验证。
- AI Key 长期保存在当前浏览器的 localStorage，调用时由 RepoPulse 服务端临时转发，不写入服务端数据库或日志。请勿在公共或不受信任的设备上保存 Key。

## 已有自建实例升级

这是首个正式 Release，没有更早的正式版本升级路径。使用预览代码的自建实例应先备份数据库并核对 schema 兼容性，再按运维手册为同一个发布提交构建前后端镜像、排空 Worker、执行 Alembic 迁移并重建服务。备份、恢复和镜像回退使用 `scripts/repopulse_ops.py`；不承诺数据库自动降级，不要用开发演示配置覆盖生产配置。

安全修复面向最新正式版本与 `main` 上的后续修复；不提供 LTS 分支，不承诺向旧版本回补修复或固定响应时间。详见 [安全策略](https://github.com/SSlaks/RepoPulse/blob/v1.0.0/SECURITY.md)。
