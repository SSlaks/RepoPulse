# RepoPulse v0.1.0-beta.1：首个公开预览

这是 RepoPulse 首个公开预览版本（beta）的发布说明。预览版用于早期体验与自建评估，接口、数据口径与页面结构仍可能变动。

## 本次预览包含

- 每日按快照记录候选仓库 Star 数，计算最近 1 / 7 / 14 / 30 天的净增长榜。
- 榜单筛选、仓库详情与趋势图。
- 自带 API Key（BYOK）的 AI「总结翻译」与全文「中文译文」。
- 冷缺 README 后台预热，正文持久化于 PostgreSQL。
- Docker Compose 自建与本地演示路径。
- MIT 许可证。

## 在线演示与本地演示

公开演示站点：<https://repopulse.slak7.cn>，展示线上公开数据，仅用于展示界面，不代表实时数据快照。

本地演示使用仓库自带的演示种子数据（静态演示），只启动核心服务，不需要 GitHub Token。仅在全新克隆且 `.env` 缺失时复制模板，不要覆盖已有 `.env`：

```bash
[ -f .env ] || cp .env.example .env
docker compose up -d --build postgres redis api frontend
```

这条命令不包含 `worker` 与 `beat`。浏览榜单、详情与趋势图不需要它们，只有采集真实数据或预热 README 时才需要。上述「不需要 Token」仅适用于本地演示，不代表线上公开站点或真实采集无需 Token。

## 真实采集与自建

- 榜单不做历史回溯。每个周期的基线是 `as_of - period` 对应的 UTC 日历日快照，且必须精确命中该日。缺少严格基线时，榜单条目显示“历史数据不足”，而不是等待对应天数后才出现榜单。1 天周期的有效净增长需等次日快照，7 / 14 / 30 天周期需积累对应天数的快照。
- 真实采集需要 `GITHUB_TOKEN` 且额度充足；多个 Token 不构成独立额度。
- 榜单只覆盖 RepoPulse 当前跟踪的候选仓库，不代表全 GitHub 排名，也不复刻 GitHub Trending 算法。
- 仅提供源码发布，不提供安装包或预构建镜像；GitHub 发布页会自动附带源码压缩包，请按文档自行构建。
- 用户自带的 AI API Key 不随项目分发，由使用者在浏览器端自行配置，不写入部署 `.env`。

## 升级说明

这是首个公开版本，没有更早的公开版本升级路径。已有的自建或内部部署在升级前请先备份数据库、执行 Alembic 迁移，并自行审阅 schema 兼容性；本项目不承诺自动化降级。

## 稳定性与已知限制

- 这是 beta 预览版，不承诺 1.0 级别的稳定性，接口与数据口径可能变动。
- AI 功能支持多个第三方提供方，实际可用性取决于对应提供方服务与你的 Key；本次发布未对所有受支持提供方执行真实付费调用验证，也不声明付费第三方 AI 服务的验证结论。
